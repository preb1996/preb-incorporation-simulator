# 法人化シミュレーター 計算仕様書 v1.0 FINAL

Status: FROZEN / IMPLEMENTATION READY  
対象年度: 2026年（令和8年）  
対象地域: 名古屋市・愛知県  
対象: 夫婦それぞれ個人事業主 vs 1法人へ統合し夫婦双方が役員  
用途: 法人化の意思決定支援。税務申告・社会保険手続そのものには使用しない。

---

## 1. 最重要原則

- 本仕様書を唯一の実装基準とする。
- 税率・保険料率・控除額は年度マスタ化し、計算ロジックへ直書きしない。
- 法人留保を個人の手取りへ加算しない。
- 国保・個人事業税・所得税で所得定義を共用しない。
- 標準報酬月額を使わずに社会保険料を直接「役員報酬×率」で計算しない。
- 消費税を「売上1,000万円超＝即課税」と判定しない。
- 仕様に矛盾が見つかった場合、実装側で勝手に直さず `SPEC_BLOCKER` として停止・報告する。
- UIは本フェーズの対象外。

## 11. 住民税 調整控除

人的控除差額は「所得税の控除額－住民税の控除額」を単純に計算せず、名古屋市公式の人的控除差額マスタを使用する。

MVP最低限:
```text

```

### 合計課税所得200万円以下

```text
base =
min(
  personalDeductionDifferenceTotal,
  totalTaxableIncome
)
```

```text
municipalAdjustmentDeduction = base × 0.04
prefecturalAdjustmentDeduction = base × 0.01
```

### 合計課税所得200万円超

```text
difference =
personalDeductionDifferenceTotal
- (totalTaxableIncome - 2,000,000)
```

```text
base =
max(
  50,000,
  difference
)
```

```text
municipalAdjustmentDeduction = base × 0.04
prefecturalAdjustmentDeduction = base × 0.01
```

合計所得金額2,500万円超:
```text
adjustmentDeduction = 0
```

最終住民税所得割:

```text
municipalIncomeTax =
max(
  0,
  taxableIncome × 7.7%
  - municipalAdjustmentDeduction
  - otherMunicipalTaxCredits
)
```

```text
prefecturalIncomeTax =
max(
  0,
  taxableIncome × 2.0%
  - prefecturalAdjustmentDeduction
  - otherPrefecturalTaxCredits
)
```

実装後、課税所得250万円程度の200万円超ケースを最低1件、名古屋市公式資料・試算値と照合すること。

## 34. 法人消費税

消費税を完全無視しない。

MVP状態:
- EXEMPT
- GENERAL
- SIMPLIFIED

新設第1期について少なくとも:
- capital
- invoiceRegistered
- taxableBusinessElection
- specificNewCorporationFlag

を判定材料とする。

原則免税候補:
```text
capital < 10,000,000
AND invoiceRegistered == false
AND taxableBusinessElection == false
AND specificNewCorporationFlag == false
```

単純な:
```text
sales > 10,000,000 → 課税
```
は禁止。

第2期の特定期間判定はMVPで自動判定しない。

原則課税:
```text
売上消費税 - 仕入控除税額
```

簡易課税:
```text
売上消費税 × (1 - みなし仕入率)
```
