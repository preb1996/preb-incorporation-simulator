# 名古屋市調整控除の公式式照合

確認日: 2026-09-14
資料: 名古屋市「調整控除」、更新2026-04-01
URL: https://www.city.nagoya.jp/kurashi/zeikin/1037356/1011880/1011883/1011893.html

公式掲載式の200万円超の分岐・最低基礎5万円・市4%/県1%を確認。
入力: 合計課税所得2,500,000円、人的控除差50,000円、合計所得3,000,000円。
独立手計算: 50,000 − (2,500,000 − 2,000,000) = −450,000。
基礎50,000円となり、市2,000円・県500円。凍結仕様第11条と一致。
GOLDEN-04-HIGH-OFFICIALの固定期待値に採用。

これは公式掲載式に対する独立計算照合であり、公式試算ツールの出力や公式掲載の数値例を取得したものではない。
住民税総額や他制度の正しさを保証する検証ではない。
