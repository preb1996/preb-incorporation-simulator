# 公式端数処理根拠

検証日: 2026-09-15

| 制度 | 課税標準 | 中間段階 | 確定税額 | 短期年度 |
|---|---|---|---|---|
| 所得税 | 1,000円未満切捨て | 復興特別所得税は1円未満切捨て | 申告納税額100円未満切捨て | 当年所得 |
| 個人住民税 | 課税所得1,000円未満切捨て | 調整控除を市・県別計算 | 市・県各100円未満切捨て | 前年所得参照 |
| 個人事業税 | 1,000円未満切捨て | 青色控除前所得から月按分事業主控除 | 100円未満切捨て | 事業主控除を明示事業月数で按分 |
| 法人税 | 所得1,000円未満切捨て | 計算税額1円未満切捨て | 100円未満切捨て | 800万円÷12×月数、端月は1月 |
| 法人県民税 | 法人税割課税標準1,000円未満切捨て | 法人税割と均等割を別計算 | 各100円未満切捨て | 均等割は存在月数按分 |
| 法人市民税 | 法人税割課税標準1,000円未満切捨て | 法人税割と均等割を別計算 | 各100円未満切捨て | 均等割は存在月数按分 |
| 法人事業税 | 所得1,000円未満切捨て | 累進区分別に計算 | 差引額100円未満切捨て | 400万/800万円を事業月数按分、端月は1月 |
| 特別法人事業税 | 確定基準法人所得割額 | ×37% | 100円未満切捨て | 法人事業税と同じ基準額を使用 |
| 消費税 | 課税標準1,000円未満切捨て | 控除後差引税額を算出 | 納付額100円未満切捨て | 年未満の課税売上高判定は月数で年換算（本MVP自動判定外） |
