# Phase 2C 仕様書 — 実用UI完成

Version: 1.1
Status: READY FOR IMPLEMENTATION
Date: 2026-09-17

## 1. 目的

このアプリは法人化前の意思決定用シミュレーターとする。
法人化後の日常経営管理には使用しない。

法人化は1月を前提とし、Phase 1 / 2A / 2Bの計算機能を変更せず、以下を比較しやすい実用UIへ仕上げる。

- 夫婦の役員報酬
- 本人負担社会保険
- 会社負担社会保険
- 法人税等
- 法人税引後留保
- 世帯可処分所得
- 世帯＋法人純資産増加

## 2. 絶対条件

1. Phase 1凍結領域を変更しない。
2. 通常計算は既存 `calculateComparison()` を使う。
3. 最適化は既存 `optimize()` を使う。
4. UI側に税・社会保険・最適化の独自計算式を持たない。
5. 世帯可処分所得、法人税引後留保、世帯＋法人純資産増加を混同しない。
6. 法人税引後留保を個人の「手取り」と表現しない。
7. 未定義条件をUIで推測補完しない。
8. 2026年・名古屋市/愛知県前提を明示する。
9. 法人化月Optimizerは作らない。1月法人化前提とする。

## 3. 実装対象

### 入力UI整理
以下へ論理分割する。

1. 基本設定
2. CASE-A 個人事業（夫・妻）
3. CASE-B 法人化（社会保険・夫婦役員報酬）
4. 法人
5. 消費税
6. 計算・最適化
7. 結果

### 12か月役員報酬
夫・妻それぞれに「全月同額」と「12か月へ反映」を追加する。
反映後も各月を個別修正できること。

1月法人化を基本シナリオとし、1月〜12月の役員報酬を同額に設定しやすくする。

### 入力補助
- 円/bpsなど単位表示
- true/false、EXEMPT等は利用者向け日本語ラベル
- 必須不足を分かりやすく表示
- エンジン由来エラーを読める形で表示

### ローカル保存
`localStorage` のみ使用。

- 保存
- 復元
- 初期化
- サーバー送信なし
- DBなし
- 保存失敗でも計算機能は壊さない

### 通常結果
最低限以下を明確に分けて表示。

- CASE-A 世帯可処分所得
- CASE-B 世帯可処分所得
- 夫 本人負担社会保険
- 妻 本人負担社会保険
- 会社負担社会保険
- 税引前法人利益
- 法人税等合計
- CASE-B 法人税引後留保
- CASE-B 世帯＋法人純資産増加
- CASE-Aとの差

### Optimizer結果
- 推奨 夫 月額役員報酬
- 推奨 妻 月額役員報酬
- CASE-B 世帯可処分所得
- 法人税引後留保
- 世帯＋法人純資産増加
- CASE-Aとの差
- VALID / WARNING と日本語説明
- Top 5

### モバイル
- iPhone幅を主対象
- 390px前後で主要画面に横スクロールなし
- タップ可能サイズを確保
- PC幅でも崩れない
